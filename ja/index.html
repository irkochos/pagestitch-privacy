プライバシー ポリシーを読む

できること・できないこと

Chrome の制約についても、正直にお伝えします。

保護されたページChrome の設定、Chrome Web Store、ほかの拡張機能のページ、HTTP(S) 以外の URL はキャプチャできません。

変化するレイアウトアニメーションするページ、読み込みが終わらないページ、スクロールに応じて変化するページは、きれいにつなぎ合わせられない場合があります。

非常に大きなページ縦や横に極端に大きい結果には、ブラウザのキャンバスの上限が適用されます。

知っておきたいこと

よくある
質問。

PageStitch はスクリーンショットをアップロードしますか？

いいえ。キャプチャとつなぎ合わせは Chrome 内でローカルに行われます。PageStitch にはサーバー、アカウント機能、アナリティクス、クラウド ストレージはありません。

対応している画像形式は？

PageStitch の書き出しは PNG のみです。現時点では PDF、JPEG、注釈、編集ツールには対応していません。

元のタブを表示したままにする必要があるのはなぜですか？

Chrome がキャプチャするのは、表示中のアクティブなタブです。キャプチャ中にタブを切り替えると別の画面が写ってしまうため、PageStitch はその場合、安全にキャプチャを停止します。

どのような権限を使用しますか？

使用するのは activeTab、scripting、offscreen の 3 つだけです。それぞれ、クリック後の一時的なページへのアクセス、拡張機能に同梱されたキャプチャ補助スクリプト、つなぎ合わせ用のローカルの非表示キャンバスに使われます。
