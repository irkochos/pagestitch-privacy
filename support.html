PageStitch support

Make one page from the whole page.

A short guide for installation, everyday capture, and the places where Chrome sets the boundary.

Getting started

Install and capture

  1. Install PageStitch from the Chrome Web Store.
  2. Open an ordinary https:// page that is taller than the browser window.
  3. Keep that source tab active, then select the PageStitch toolbar button.
  4. When the local result page opens, preview the PNG and choose Download image or Copy image.

When a page will not capture

A few important limits

  • Protected pages: Chrome system pages, the Chrome Web Store, other extension pages, and non-HTTP(S) URLs cannot be captured.
  • Keep the source tab active: do not switch tabs while capture is in progress; PageStitch needs the selected tab to remain active.
  • Very large pages: unusually tall or wide pages can exceed browser image limits and may not stitch perfectly.
  • Custom scrollers: pages with nested or custom scrolling areas can produce incomplete or imperfect captures.

Copy image

If clipboard copy is unavailable

Copy image uses Chrome’s Clipboard API only after you select the button. Chrome or your operating system can refuse that request. If it does, use Download image and paste or attach the saved PNG from your computer instead.
