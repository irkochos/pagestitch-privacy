Límites claros

Honestos sobre dónde pone Chrome el límite.

Páginas protegidasNo se pueden capturar la configuración de Chrome, Chrome Web Store, las páginas de otras extensiones ni las URL que no sean HTTP(S).

Diseños cambiantesLas páginas con animaciones, que nunca terminan de cargar o que cambian al desplazarse podrían no unirse a la perfección.

Páginas muy grandesLos límites del lienzo del navegador se aplican a resultados inusualmente altos o anchos.

Preguntas,
respondidas.

¿PageStitch sube mis capturas de pantalla?

No. La captura y la unión se hacen localmente en Chrome. PageStitch no tiene servidor, sistema de cuentas, analíticas ni almacenamiento en la nube.

¿Qué formatos de imagen admite?

PNG y PDF. Guarda una captura como PNG o como PDF en una sola página larga, A4 o US Letter. Un editor integrado gratuito añade recorte, flechas, formas, resaltado, texto, emoji, desenfoque, un sello de página y una marca de agua. JPEG no es compatible.

¿Por qué la pestaña de origen debe seguir activa?

Chrome captura la pestaña activa visible. Cambiar de pestaña durante la captura devolvería píxeles equivocados, así que PageStitch se detiene de forma segura.

¿Qué permisos usa?

Solo activeTab, scripting y offscreen: acceso temporal a la página después de tu clic, un asistente de captura incluido en la extensión y un lienzo local oculto para unir las imágenes.
